# Viper-Simple-font-view
A lightweight, open-source font viewer for Windows. Scan folders, preview fonts, and explore font families.

It all started when I noticed that similar software on the market was paid. I boldly thought: maybe, in this boring phase of my life, I could build something helpful for those who need it — font designers, illustrators, painters, and anyone who wants to quickly view and study fonts. There are still imperfect features and bugs, but I'll do my best to push a small update every day. You're welcome to become one of my "original shareholders."

Oh, and by the way — this is a very lightweight and convenient offline tool.
